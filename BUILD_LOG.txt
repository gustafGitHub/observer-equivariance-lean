Import surface
--------------
Core.lean, Cocycles.lean, ResidualCategory.lean and Examples/Twist.lean import the specific mathlib
modules they use instead of the blanket `import Mathlib`. This is why `lake build` reports 2272
jobs; with the blanket import the same tree required 8518. It changes no statement and no proof
body. It does shift the DECLARATION COUNT below, because that count includes generated auxiliary
constants (_proof_n, match_n) and which of those are generated depends on the instances and simp
lemmas in scope: the same tree reports 2766 declarations with the narrowed imports and 2761 with
the blanket import. The count is therefore a property of this pinned configuration, not of the
mathematics.
